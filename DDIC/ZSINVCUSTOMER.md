
# ZSINVCUSTOMER

**Short Description:** INVOICE CUSTOMER DETAILS

| Field | Data Type | Type | Length | Description |
|---|---|---|---:|---|
| KUNNR | KUNNR | CHAR | 10 | Customer Number |

| LAND1 | LAND1 | CHAR | 3 | Country/Region Key |

**Purpose:**
