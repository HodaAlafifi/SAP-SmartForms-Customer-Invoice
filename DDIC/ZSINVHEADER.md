
# ZSINVHEADER

**Short Description:** INVOICE HEADER DATA

| Field | Data Type |
|---|---|
| VBELN | VBELN |
| FKDAT | FKDAT |
| KUNAG | KUNAG |
| WAERK | WAERK |
| NETWR | NETWR |

**Purpose:**
Stores the invoice header information, including invoice number, billing date, customer number, currency, and net value.
